# Rise 转头对齐

参考 `skid/Rise-6.9.5-main` 的 `RotationComponent`、`RotationUtil`：
平滑后采用 `(sensitivity * 0.6 + 0.2)^3 * 8 * 0.15` 步长，
使用 Java Math.round 的舍入规则，随机灵敏度微扰分母对齐为 1000000。

Nova 的普通、线性、直接及独占请求统一在管理器内进行最终量化，
以最近的 Motion 输出为基准，避免真实摄像机与静默角度使用不同原点。
线性模式累计不足一个鼠标步长的余量，保留低速与各轴零速设置；
回正到量化后的目标即可结束，避免等待无法精确到达的浮点角度。
无法读取有效灵敏度时暂缓自动角度提交，恢复 JNI 后可继续。
直接请求的调用方记录实际接受的角度，用于释放归属判定。

Rise 回正中的 `applySensitivityPatch` 后接 `RotationUtil.o`，
后者恢复真实 yaw 的方向及真实 pitch；不能将前一个调用单独视为
最后的回正角度。因此保留 Nova 的整圈重定位及手部插值修复，
不通过归一化发包 yaw 或更改真实视角来实现对齐。

现代版本的物品使用事务锁定量化后的角度，后续请求、回正及移动包
继续复用同一浮点值。沿用现有移动修复策略与模块速度单位，
没有移植 Rise KillAura 的全部转头模式或修改任何反作弊检测阈值。

回归覆盖多种灵敏度、真实摄像机移动、跨 ±180 度、低速累积、
轴锁定、回正结束、JNI 读取失败、整圈 yaw、手部连续性，以及
同 tick 的攻击／物品使用／移动角度一致性。测试不构成服务器封禁原因的确认。
