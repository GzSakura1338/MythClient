# FakePlayer

入口：Misc → FakePlayer。支持 Lunar 1.21.11 和 Minecraft 26.3。其他版本开启会提示并关闭。

开启时在玩家当前位置生成名为 FakePlayer 的静止本地假人。走开后即可看到、瞄准和攻击它。复制已加载的皮肤信息，并按 Copy Equipment 开关深拷贝头盔、胸甲、护腿、靴子和双手物品；不会共享或修改真实背包。缺少本地皮肤信息时使用游戏默认皮肤。

| 设置 | 默认 | 作用 |
|---|---|---|
| Copy Equipment | 开 | 生成时复制装备和手持物品 |
| Health | 20 | 生成/自动恢复后的生命值，2 点为一颗心 |
| Auto Reset | 开 | 致死后恢复所设血量，方便重复测试 |
| Simulate Damage | 开 | 本地近战和爆炸伤害模拟、原版受伤闪红 |

近战按攻击属性、攻击冷却比例、护甲/韧性和抗性模拟；重击、武器附魔、服务器自定义伤害未完整复现。爆炸根据收到的爆炸中心/半径，复用水晶的原版遮挡采样和防御读取，再计算难度、距离、护甲及保护/爆炸保护。网络延迟、遮挡变更和数据包延迟回放可能让估算与服务器伤害不同，因此用于功能测试，不作为精确伤害基准。

假人有独立 UUID 和避冲突的负实体 ID，不注册为服务器玩家。近战在原版控制器入口转为本地扣血并重置攻击冷却；所有发送到该假人 ID 的实体交互包都在网络入口拦截。正常玩家不走此逻辑。Teams、AntiBot 对本模块自己的实体放行，HealthBypass 不覆盖其模拟血量。

关闭模块、玩家死亡、换世界会删除假人；关闭 Auto Reset 后被击杀也会删除并关闭模块。实体创建、移除和血量修改均在游戏线程执行，渲染线程只发布设置，网络线程只将爆炸值放入有上限的队列。熔断等待游戏线程移除假人，再恢复字节码和卸载 DLL；若游戏线程卡死无法清理，则保留 DLL 并记录日志，避免留下失效回调。

验证：

```powershell
& Client/test/misc/fakeplayer/run.ps1
& Client/test/misc/fakeplayer/mapping.ps1
```

运行测试编译生产适配器，替换 JNI 边界，覆盖创建/删除、装备深拷贝、近战冷却、爆炸队列、死亡恢复、实体 ID 冲突、换世界、移除失败重试、线程约束。45 个游戏 JNI 绑定对两个实际 jar 校验；Lunar 的 GameProfile 构造器通过 Recaf 核对。未代替用户实机注入测试。
