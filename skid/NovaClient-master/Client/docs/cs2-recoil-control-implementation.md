# Recoil Control 实施记录

2026-09-22，CS2 Build 14181。设计见 [设计文档](cs2-recoil-control-design.md)。

## 已接入

Combat → General → **Recoil Control**，默认关闭、无默认按键。Horizontal / Vertical 为 0–100%，默认 100%；Start Bullet 为 1–10，默认 2；Smooth 为 0–100 ms，默认 0。设置、绑定、配置和 ArrayList 使用现有 ModuleManager 与公共 UI。

按 Item Definition Index 自动识别全部 34 种枪械，M4A4/M4A1-S、P2000/USP-S 分开识别；Zeus、刀、投掷物、C4 不参与。不需要选择枪名，不自动开火，不需要目标或 Team。直接跟踪原生合成 AimPunch，不套固定鼠标下拉曲线，也不消除随机散布。

## 输入链路与 ABI

当前 client SHA256：`A0C195F0B6EC00915EF08C548200A010EBBE7982D3A4BC468CAD939B67C8C4E3`。同时复用 SDK 的 engine SHA256、Build 校验，并核对下列入口与调用点字节。版本不符只禁用 Recoil Control。

| RVA | 当前版本静态分析结果 |
| --- | --- |
| `0xB1C000` | 为输入工作向量追加一个 0x440 字节样本；复制上一个样本的视角，首个样本复制 input+0x688 |
| `0xB38A40` | 原始输入处理，最终视角位于样本+0x430；样本+0x18 实际是移动量，并非外部 SDK 所标的视角 |
| `0xB38E96` | 最后一次调用 `0xBA3E20`，RCX=宿主上下文，EDX=slot，R8=当前样本+0x430；返回地址 `0xB38E9B` |
| `0xBA3E20` | 根据 slot 找本地 Pawn，调用 `0xAD9970` 提交相机使用的 eye angles；RAX 返回值原样保留 |
| `0xAD9970` | 旧 Pawn+0x12C0 视角复制到历史，再复制传入角度到当前视角 |
| `0xB2D1A0` / `0xB3D3F0` | 原版读写视角均选择当前工作样本+0x430，无样本才使用 input+0x688 |
| `0xCB4EA0` → `0xCA8920` | 后续读取已呈现的帧数据，构造、序列化输入历史 |
| `0x82B780` | RCX=AimPunchServices，RDX=8 字节 tick/fraction 输出；取得原生时间上下文 |
| `0x82B500` | RCX=服务，RDX=三个 float 输出，R8=时间指针，R9B=是否缩放；返回 predictable + unpredictable 的有效角度 |
| `0x224270` | 当前构建的原生 interval getter 返回 0.015625；与求值器内部 128 段离散计算无关 |
| `0xB20960` | 读取 input+0x10 起的 64 个注册 kbutton，button+0x32 表示按下；本实现只读其状态，不调用该函数的按下/抬起记录副作用 |
| `0x4EBE10` / `0x4EBC40` | 原版 CreateMove 查询输入抑制计数；对应静态地址 `0x207E9B0`，非零时不输出 |

输入指针取自 `client+0x20C54E8`，工作向量 count/pointer 为 input+0xB50/+0xB58。外部 dump 将 count 标成 command number、把另一 RVA 标成 input singleton，不能直接采用。

Hook 安装在 `0xBA3E20`，**仅接受返回地址为 `0xB38E9B` 且 slot=0 的调用**。再次验证传入角度指针恰好对应原版工作向量的最后一个样本。其他所有调用透传。

在这个原版提交调用前修正工作样本，然后让原函数复制同一角度给 Pawn。没有 Present 写视角、没有事后遍历/涂改 protobuf 历史、没有修改攻击索引、发包或开火按钮。最后一个输入回调虚函数在当前版本为 `nullsub_2802`，不会再覆盖角度。

## 控制器与状态边界

- 当前输入已包含前一次修正，控制器只增加累计修正的变化量，保留鼠标运动和 Roll。
- Smooth 使用 `1-exp(-dt/tau)`；0 ms 立即响应。Yaw 使用最短角差，Pitch 限制在 ±89°，截掉的修正不累积成后续欠账。
- 最后开火时间变化，与 shots/弹匣/recoil index 变化交叉判断实际射击。R8 蓄力不算开火，霰弹枪不按弹丸数累加。
- 阈值前持续更新基线，切换开关/参数后重新采样，不补偿之前欠下的角度。
- 本轮已发生射击且按住相应开火键时持续反馈。Glock/FAMAS 连发余弹允许松键后继续；实际新射击先于空弹匣判断。
- 停射停止输出，不回拉至原来朝向，不继续消耗 Smooth 剩余量；闲置的落地/受击不触发补偿。射击期间的合成 AimPunch 可能包含落地等分量，仍按设计整体反馈。
- 对本地 Pawn、武器、所有者、实体槽序号和身份回链做校验；切枪、句柄重用、会话变化、死亡、失焦、ClickGUI、原生输入抑制、重载、消音器切换和时间中断重建基线。
- 64 项有界检查点按 frame/样本序号/身份保存补偿前状态；重复样本从检查点重算，已修正输出不会被二次扣除。原版命令重预测通常复用已生成样本，不经过这个原始输入提交点。
- UI 只通过一个 64 位原子值发布完整设置及变化代数，游戏输入线程独占控制器。禁用/启用即使发生在两个输入样本之间，也会使旧状态失效。
- Hook 计数覆盖原函数、SEH 异常展开和停止排空。熔断先停输入 Hook，再清理 SDK/渲染；适配器异常停用 RCS，原版异常不被吞掉。无静态 TLS。

## 文件职责

- `src/cs2/modules/combat/recoilcontrol/`：模块参数和独立数学控制器。
- `src/cs2/sdk/weapons/`：枪械快照、版本字段、原生后坐力求值与输入快照。
- `src/cs2/hooks/InputHook.*`：最终输入提交、设置快照、Hook 生命周期。
- `test/cs2/RecoilTests.cpp`：纯逻辑、模拟实体内存和真实 MinHook 的合成原生函数测试。

## 验证边界

独立测试验证：34 个枪械编号、排除非枪械、完整句柄/所有者校验、轴比例、Start Bullet、Smooth 采样率、Yaw 跨界、Pitch 限制、鼠标保留、停射、空弹匣末发、连发、R8 蓄力、参数/身份/时间切换、重复样本与检查点重算。合成原生函数验证参数/返回值透传、限定调用者、相机与工作角度同值、异常排空、关闭和重新安装。

**尚未在真实 CS2 中注入或实射验收。** 当前是静态二进制验证、独立测试和构建验证；真实输入调用时序、服务器命中方向与各枪效果仍需用户注入后验证。不要把合成 ABI 测试理解为已经执行过游戏内部函数。初测可使用 AK/M4，Horizontal=100、Vertical=100、Start Bullet=2、Smooth=0；随后检查切枪、开镜、菜单、停射、熔断再注入及 Glock/FAMAS 连发。
