# BridgeAssist

BridgeAssist 只负责手动搭路时的边缘自动蹲伏。手持方块、视角向下至少 45°、站在地面且没有向前走时自动判断；停在边缘也继续保护。放好下一块且脚下与预测位置恢复支撑后，再松开自动蹲。

除通用启用/绑定外，仅保留两项设置：

| 设置 | 默认值 | 范围与作用 |
|---|---|---|
| Edge distance | 0.08 | 0–0.25 格；脚底中心周围的安全距离，越大越早蹲 |
| Release delay | 50 ms | 0–200 ms；恢复支撑后保持蹲伏的时间，按游戏 tick 向上取整，0 为立即松开 |

移除了旧的 Pre Place 转头、Sneak on Jump、Sneak Key Pressed、Holding Blocks、Looking Down、Not Moving Forward 和 Debug 配置。手持方块、低头和前进判断改为内部条件；跳跃、离地、打开聊天/背包/ClickGUI、启用 Scaffold 时停止自动接管。用户的手动蹲和其他模块已经设置的蹲伏不会被清除。

实现分成短距离支撑探测、当前/预测位置检查和按 tick 计时的松蹲状态。支撑探测从实际脚底高度发出短射线，排除无碰撞的方块轮廓；不再将所有方块当作整格，也不把远处下层地面当作脚下支撑。预测位置缺少地面时立即视为边缘，并检查中点避免仅看终点漏掉空隙。这是局部探测，不是完整移动物理模拟，特殊碰撞形状仍需实际游戏验证。

松蹲延迟要求当前与预测支撑持续恢复，重新遇到边缘会重置计时。切换玩家对象、tick 回退、关闭/重新开启模块时会清除旧状态。模块只对当前输入事件添加蹲伏，不修改按键绑定或接管放置、转头。

旧配置中模块开关和绑定仍按原名称读取；旧模块专属参数不再读取，新参数使用上表默认值，保存配置后写入新字段。

离线回归：`Client/test/player/bridgeassist/run.ps1`，使用真实模块源码配合模拟世界，覆盖设置数量、边缘/斜向/负坐标、半砖高度、预测空隙、松蹲计时、手动输入、Scaffold 互斥、玩家切换及重启。离线测试不代表游戏内验收；由用户注入后验证各版本的直搭、斜搭、放块后松蹲与界面/跳跃切换。
