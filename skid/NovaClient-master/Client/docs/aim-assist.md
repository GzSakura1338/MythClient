# AimAssist 线性瞄准

FOV 表示以实际准星方向为中心的完整锥角，同时约束水平、垂直和斜向偏差。例如 30° 允许瞄准点偏离准星最多 15°，360° 表示全方向。Normal、Silent 都按实际摄像机方向检查，Silent 不使用发包角度作为 FOV 中心。选敌与持续跟踪使用同一实际身体瞄准点；每次转头前重新读取 FOV 和视角，超出范围立即解除锁定，遮挡备用点也必须在范围内。这是辅助选敌范围，不改变 Minecraft 的画面视野。

## 转头速度

Mode 仅保留 `Normal / Silent`。Normal 在满足按键、范围等条件时主动跟踪目标，不要求鼠标持续移动。

- Normal 的 `Horizontal speed` 控制左右速度，`Vertical speed` 控制上下速度；范围均为 0–720 deg/s，默认 180，0 关闭对应轴转头。
- 两个轴分别按实际帧间隔推进，到达目标后停止，不叠加随机抖动。斜向转动时两个轴各自使用自己的速度上限。
- `Smooth`：仅 Normal 显示，默认关闭。小齿轮中的 `Smooth amount` 可调 0–100%，默认 50%。强度控制目标/自身位置的渲染插值和上一帧视角的同步修正，减少 tick 更新带来的跳顿；100% 使用完整修正，0% 等同关闭。左右/上下速度始终按原设置推进，不因接近目标或提高 Smooth 强度而额外减速。移动目标按游戏渲染位置跟随，有最多一个 tick 的渲染插值偏移；大幅瞬移时跳过位置插值。
- Silent 继续使用 `Turn speed`（10–720 deg/s），保持原有的合成角速度和静默移动修正逻辑。

旧配置中 Linear 自动迁移为 Normal。显式保存的水平、垂直速度优先保留；如果缺少某轴设置，则从旧 Turn speed 初始化该轴。Linear 专用鼠标回调和辅助算法已删除。

点击 `Mode` 右侧的小齿轮，展开 `Aim` 目标模式：

- `Single`（默认）：锁定当前有效目标；目标死亡、离开范围/FOV 或不再满足筛选条件时重新选择。
- `Switch`：在有效目标中按现有 Sort 顺序轮换。小齿轮内显示 `Switch delay`，默认 250 ms，可调 0–1000 ms；0 表示每次游戏 tick 的目标选择都可切换。

两种目标模式都适用于 Normal/Silent，不改变线性转向速度。目标列表重新排序时按实体身份跟踪当前目标，只有一个有效目标时继续瞄准该目标。

同一个小齿轮中的 `Aim part` 可选择 `Head / Chest / Legs`（头部/胸部/腿部），默认 Head。瞄准点按目标当前碰撞箱高度计算；多点参数在所选部位的高度范围内调整，不会把腿部优先直接拉回头部。开启遮挡过滤时，先尝试优先点，再按距离优先点的远近寻找其他可见位置；这是部位优先而非强制锁死该部位。Normal/Silent、Single/Switch 均使用同一套部位选择。

旧配置中的 `Mode: Normal/Silent` 仍能读取，新增 Aim 默认 Single；保存后，Mode 及其小齿轮参数会按带子设置的格式一起持久化。

- `Normal`：按实际帧间隔推进摄像机，每帧从当前真实视角开始，因此不会反复回写旧 tick 的起点；长于 250 ms 的停顿会重置本帧计时，避免恢复时猛转。
- `Silent`：通过旋转管理器按每游戏 tick `Turn speed / 20` 的角度预算推进，仅影响静默旋转，不叠加原有随机/灵敏度平滑。游戏低于 20 TPS 时，其实际每秒速度会随 tick 变慢。

保留 FOV、Range、Sort、多点瞄准、隐身/队友/遮挡过滤、鼠标与武器条件、挖掘暂停和静默移动修正。不提供 `Randomization`；旧 `Speed` 是不同单位，旧配置不会套用到新速度，新字段使用默认值。

启用 Scaffold、KillAura 已有目标或其他模块正在控制普通旋转时，AimAssist 让出控制。松开必要鼠标键、打开界面、目标失效或切换模式时立即停止当前瞄准。释放 AimAssist 的静默请求不会取消其他模块后来提交的普通旋转请求。

离线回归：`Client/test/combat/aimassist/run.ps1`。覆盖固定角速度、斜向步长、跨越 ±180°、俯仰范围、到点停止、不同帧率、停顿恢复，以及真实旋转管理器的静默分支、重复调用与请求优先级。游戏内普通/静默表现由用户注入后验证。
