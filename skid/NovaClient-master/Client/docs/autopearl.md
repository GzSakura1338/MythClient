# AutoPearl

Player → AutoPearl，使用模块本身的 Bind。每次开启扫描快捷栏，从左到右选择珍珠，沿当前视角调用一次原版右键使用，然后自动关闭；不自动瞄准、不取背包物品。

切槽使用共享物理槽位租约，使用前同步选中槽位。成功、使用失败或返回不明均不自动补投。下一 GameTick Pre 切回触发前的槽位并同步；模块关闭、界面打开或失去焦点不取消这一恢复任务。读取、写入或同步暂时失败会保留任务并重试。手动滚轮/数字键改选其他槽位则尊重手动选择；换世界清理旧恢复任务，不修改新世界的槽位。

AutoMLG、AutoCharge、AutoMace、AutoBlock/AutoRod 交互占用、其他转头控制或原版正在使用物品时暂缓；最多等待 60 tick 后取消。珍珠冷却遵循原版，拒绝使用后仍切回，不自动连丢。旧版使用现有 HeldSlotChangeReady 门槛，现代版使用共享物品事务。

验证：`Client/test/player/autopearl/run.ps1` 直接编译生产模块并模拟游戏接口，覆盖 81 组原槽位/珍珠槽位、单次提交、下一 tick 切回、使用/读取/写入/同步失败、手动切槽、关闭模块/界面/失焦、切世界和旧版门槛。模拟不代表服务器实际接受投掷；由用户自行注入验证。
