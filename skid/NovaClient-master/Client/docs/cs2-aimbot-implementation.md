# CS2 Aimbot 实施说明

2026-09-24：删除 Rage 模式、瞬间转头、自动开火参数及专用攻击输入 Hook。现在仅保留普通线性辅助瞄准，开火由用户控制。当前版本偏移以 src/cs2/sdk 为准；旧版逆向报告仅作历史参考。

## 使用

Combat → General → Aimbot，默认关闭。绑定默认 Hold 且未分配按键；先设置绑定，再按住使用，也可改为 Toggle。默认同时要求按住物理鼠标左键。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| Aim FOV | 5° | 玩家身体进入辅助范围的三维夹角，0.1–180° |
| Horizontal Speed | 120°/s | 水平线性转速，0–720；0 停止该轴辅助 |
| Vertical Speed | 90°/s | 垂直线性转速，0–720；0 停止该轴辅助 |
| Smooth | 0 ms | 0–500，步长 5；0 保持线性，越大越缓和接近目标时的转动 |
| Target | Single | Single 保持有效目标，Switch 选择更近方向，内置 0.35° 切换迟滞 |
| Aim Priority | Chest | Head / Chest / Pelvis 为优先部位；人物入圈后优先瞄准该部位，不要求该部位也在圈内；不可见时回退到圈内其他可见部位 |
| Show FOV | 开启 | 绘制公共 UI 范围圈 |
| Only While Clicking | 开启 | 按住物理鼠标左键时辅助 |
| Recoil Compensation | 开启 | 补偿完整 AimPunch，与独立 Recoil Control 协作 |

Team 统一过滤队友。只处理存活、非休眠、无免疫的 T/CT 玩家，几何射线判断墙体和实体遮挡。没有烟雾或闪光过滤。本地须存活、持有效枪械且有弹药，换弹或切换消音器期间暂停。菜单、失焦、输入被抑制、松开 Hold、目标失效时停止辅助。

每个玩家收集当前模型的头、躯干、手臂和腿部命中框中心，一次获取模型变换。先确认至少一个身体点位于 FOV 内且可见，再选择该玩家的可见优先部位，即使优先部位位于圈外。例如只有脚进入范围、头部可见时，Head 会向头部转动。优先部位被遮挡或可见性未知时才回退到圈内可见身体点；没有任何可见身体点入圈时不获取该玩家。单次采集缓存可见性，避免重复射线。范围判定点与最终瞄准点分别传给控制器，玩家之间按范围判定点执行 Single/Switch，转向优先部位仍受转速与 Smooth 限制。

Smooth 使用受转速上限约束的指数接近：较远时保持最大线性速度，接近目标时逐渐减速，不超调。按输入样本时间积分，避免帧率改变平滑强度；水平/垂直速度为 0 仍关闭该轴辅助。平滑作用于目标转头，连续锁定期间的后坐力差值仍单独补偿。切换部位或目标同样受速度和 Smooth 约束。

范围圈复用 ui/hud/aim/FovCircle.h，根据当前投影及窗口高度计算，支持开镜与 FOV Control。Aim FOV 是半角；89° 以上不绘制无法投影的有限圆环，但筛选仍按参数执行。

## 实现与配置

- modules/combat/aimbot/Aimbot.*：设置、范围圈、绑定及设置发布。
- AimController.*：Single/Switch、每轴限速、Smooth、后坐力补偿及重复样本处理。
- sdk/aim/AimSnapshot.*：实体身份、命中框、射击起点、几何射线。
- input/AimPipeline.*：Aimbot 与 Recoil Control 协作。
- hooks/InputHook.*：最终角度提交，保留原生返回值及其他调用者行为。

仅输入回调读骨骼并修改角度，Present 发布设置。64 个样本的历史用于处理重放，避免重复转头或压枪。身份变化、时间倒退或超过 250 ms 的间隔重建基线；首次有效样本只建立时间基线。没有攻击按钮写入，也不再安装外层自动开火输入帧 Hook。

AimPipeline 在后坐力处理和重复样本还原后提供统一参考角，部位采集与最终目标选择使用相同参考。已锁定玩家仍需有可见身体点处于 FOV 内；控制器不再把最终优先部位单独按 FOV 拒绝，也不通过扩大 FOV 保持目标。

开启 Recoil Compensation 时，有目标的 Aimbot 负责完整补偿，避免与独立 RCS 叠加；连续锁定期间，新后坐力变化不占用目标转头速度预算。关闭后沿用独立 RCS 已应用的累计偏移。真实鼠标移出 FOV 会解除锁定。瞄准采集异常仅停用 Aimbot，独立 RCS 仍可继续。

旧配置中的 Mode 及自动开火设置被忽略，保存时移除；原先 Mode/sub/Recoil Compensation 会迁移到同名独立设置，Aim Point 迁移为 Aim Priority，新格式优先。旧配置没有 Smooth 时默认为 0。Hold 的瞬时启用状态不持久化。

## 验证

NovaCs2Smoke.exe --aim-only 覆盖优先部位与其他部位回退、遮挡/未知可见性、锁定对象 FOV、部位恢复、后坐力脉冲与重放参考角一致性、30/60/144/240 FPS 平滑一致性、速度上限与零轴、反向转动、不超调、配置迁移和保存恢复；同时保留几何、绑定、异常隔离及重新安装测试。完整 smoke 覆盖 DX11 UI、配置与卸载。产物为 Client/build-vs2026/Release/NovaClientBase.dll。

实际游戏中的骨骼、Trace、输入时序与视觉效果仍由用户注入验收，离线测试不代表实机效果。
