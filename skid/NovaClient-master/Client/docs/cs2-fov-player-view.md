# FOV 玩家视角范围

Build 14183。FOV 设置只作用于存活的本地玩家、第一人称观战（mode 2）和跟随观战（mode 3）。固定镜头、自由观战、死亡目标、实体相机覆盖及 CCSCameraManager 的活动镜头均不调整，结算时每帧保留原生 OverrideView 结果，不缓存或回写旧 FOV。

相机判断使用控制器当前 `m_hPawn (+6BC)`，不使用只代表战斗玩家的 `m_hPlayerPawn (+92C)`。IDA `969900` 验证了原生相机路径使用前者；死亡后它可以指向 ObserverPawn。观战从 ObserverServices `+1308` 读取模式 `+48` 和目标句柄 `+4C`，验证目标是存活的 C_CSPlayerPawn，并读取目标自身的相机服务和开镜状态。

`CCSCameraManager` 实例 `25743D0` 的活动镜头位于 `+28`。`D015F0` 在非空时还会 dynamic_cast 检查 `CDataDrivenCamera`，只有匹配该类型才覆盖位置、角度和 FOV。不能仅凭活动镜头非空就排除玩家视角。本模块通过有界读取 MSVC RTTI 基类列表匹配类型描述符 `22F21D0`，排除数据驱动镜头及其子类；无法读取或类型结构异常时也跳过。相机服务的 `m_hViewEntity (+A4)` 如指向其他实体，也不修改。

保留现有 FOV 范围、Preserve Zoom 和 Remove View Shake 设置。去抖只用于本地玩家，观战镜头不套用本地输入角度。捕获完成前复核视角来源，切换目标或进入结算期间出现不一致就跳过当前帧。

2026-09-24 修正：在 `ClientModeShared::SetupView (B9B570)` 返回后应用 FOV，不再挂在中途的 `OverrideView (D015F0)`。前者在后半段还会调用相机和武器视角计算，并将 4:3 参考 FOV 换算为当前宽高比。设置按 4:3 参考角度处理，然后换回当前画面的水平角度。保留原生返回值和所有原生调用。

启用时日志每 5 秒记录 `setup frames`、`applied` 和视角校验状态。安装成功只能证明字节校验及 Hook 安装通过，不能作为游戏内视觉效果的验收结果。

FOV 离线测试覆盖存活玩家、死亡后的两种观战、结算相机仍有存活 Pawn、自由/固定镜头、实体覆盖、目标死亡、句柄复用、目标切换及断线。离线测试不替代游戏内结算和观战验证。
