# CS2 FOV Control

## 用户设置

入口：Render → General → FOV Control，默认关闭。

- FOV：30–150，步进 0.1，默认 90。未开镜时固定使用所选世界相机视野，持枪、切枪和退镜残留插值不会改变它。不调整手部模型参数。
- Preserve Zoom：默认开启。只有本地玩家实际开镜时，才以原版基础视野为基准保留开镜放大倍率和开镜中的过渡；退出开镜即恢复所选 FOV。关闭时固定使用所选 FOV，包括开镜时。
- Remove View Shake：默认开启。第一人称使用当前输入角，移除相机额外附加的角度抖动；启用 Aimbot/RCS 时读取匹配该输入的补偿量，避免压枪输入造成额外画面跳动。不隐藏目标跟随转头，不修改弹道散布、后坐力状态或武器模型动画；第三人称不覆盖角度。
- 设置、开关、绑定和 ArrayList 由现有模块管理器统一处理。

数值使用游戏原生视野单位，宽高比处理继续由游戏完成。更改立即作用于下一次已发布设置的相机计算。死亡、旁观、断线和非本地相机不覆盖。关闭、卸载不需要恢复玩家属性，因为从未改写持久相机字段。

## 原生适配

Build 14181，2026-09-22 对本机 client.dll 副本进行 IDA 分析；沿用 `sdk/players/Offsets.h` 中 client.dll / engine2.dll 的 SHA256、镜像大小和构建号校验。SDK 还校验两个函数的入口字节。

- 最终视图 Hook：`client + 0xCB2930`，签名 `void __fastcall(void* clientMode, void* view)`。只处理调用返回地址 `0xBCC779`，校验 ClientModeCSNormal 虚表 `0x1B5A560`、对象 `+0x28` 的 slot 为 0，再验证本地相机。
- 旧世界 FOV getter：`client + 0x8626E0`，相机虚表槽 `0x118`。已不 Hook 它。IDA 复核发现开镜相机 `0x85A4C0` 在调用此槽后仍会通过武器 getter `0x8091E0` 和缩放过渡 `0x859180` 再次写 FOV，因此旧改动可被覆盖；这是本次针对 SG 553 反馈修复的路径，尚需实际持枪验收。
- 当前在原版 OverrideView 返回后修改 view `+0x498` 世界 FOV；位于相机角度缓存与投影矩阵生成之前，后续仍由游戏处理宽高比。原版世界 getter、武器开镜、ClientMode 逻辑都完整执行，只应用一次设置，不重复缩放。
- 基础 FOV：`client + 0xA2B380`，同一签名，虚表槽 `0x120`。读取原版 controller FOV / game rules 默认值。运行时只调用匹配已验证地址的虚表入口。
- Pawn 相机服务：`0x1240`；服务所属 Pawn：`0x38`。同时验证已连接、controller/Pawn 对应关系、实体句柄序号/身份回链、存活状态和 T/CT 队伍。
- 实际开镜状态：Build 14181 的 `C_CSPlayerPawn::m_bIsScoped`，偏移 `0x1C78`，来自 `skid/cs2-dumps/20260922-build14181-full/a2x/client_dll.hpp`。与相机所属 Pawn 在同一次回调中采集，完成身份复查后才发布；读取失败不覆盖原版结果。不使用 `m_bResumeZoom` 或原版 FOV 与基础值的差异猜测开镜状态。

原版视图处理始终先执行，保留 `m_iFOVStart` 等过渡记账、枪械缩放、开火后视野恢复。Hook 只调整当次视图。未开镜直接使用所选值；实际开镜且开启 Preserve Zoom 时，保留倍率的计算为：

`2 * atan(tan(configured / 2) * tan(native / 2) / tan(base / 2))`

角度先换算为弧度；不是直接把原版视野乘固定比例。基础视野由原生 getter 提供，未硬编码成 90。原始或基础视野无效时返回原值。

角度输出位于 view `+0x4B8`。未抖动输入读取 Pawn `+0x12C0`，由已核对的 `0xAD9970` 最终输入提交函数写入；input 对象 `+0x229` 为第三人称标记。输入补偿快照用短 SRW 锁复制，包含 Pawn 完整句柄、最终输入角、设置代数和时间戳，只接受完全匹配且距今不超过 100 ms 的记录。菜单、失焦、输入采集失败、设置变化、停止/卸载时不接受过期快照。修改范围是当次渲染视角，原版输入和射击数据保持原语义。

## 生命周期和验证

模块只发布一个原子设置快照（FOV 按十分之一度打包），游戏相机线程完成读取和计算。Hook 无跨帧实体指针缓存；原版异常继续传播，自有适配异常让功能停用。卸载先禁用 Hook，再等待包含原版执行在内的回调排空，最后移除跳板。

`NovaCs2Smoke.exe --fov-only` 覆盖原版后续开镜写入后的最终覆盖、0.1 步进、视角抖动开关/第三人称透传、未开镜持枪/切枪 FOV 波动、退镜残留插值、实际开镜的投影倍率与过渡单调性、开镜标记缺失/非法值/身份变化、参数边界、非有限值、非默认基础视野、相机所有权/死亡/旁观/断线、句柄复用、真实 MinHook 的两参数 void ABI、原版副作用、配置往返、开关、异常、排空和重装。输入补偿快照与小 FOV 连续射击由 `--aim-only` 覆盖。完整 smoke 同时覆盖现有 UI 与其他 CS2 功能。

测试使用独立进程中的模拟相机和生产 Hook，不注入 CS2。实际游戏中的普通视野、各类开镜、死亡/复活、切服和熔断效果仍由用户注入验证。游戏版本变化时需要重新验证地址和指纹；不匹配时 FOV Control 不启用。
